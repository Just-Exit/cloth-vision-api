# 기능 요구사항

## 1. 표기

- 우선순위 `P0`: 핵심 사용자 흐름 또는 출시를 막는 요구사항
- 우선순위 `P1`: P0 데이터에 기반한 가치 확장
- 우선순위 `P2`: 외부 연동 또는 고급 기능
- 상태 `완료`: 현재 코드와 테스트에 존재
- 상태 `부분`: 일부 기반만 존재
- 상태 `미구현`: 핵심 동작이 없음

## 10. 공통 완료 조건

기능은 다음 조건을 모두 충족해야 완료다.

- OpenAPI 요청/응답 계약이 문서화됨
- 인증과 사용자 소유권 검사가 적용됨
- migration과 rollback 전략이 존재함
- 정상/실패/권한/경계값 테스트가 통과함
- 로그에 token, 이미지, 사용자 노트가 노출되지 않음
- 화면의 loading/empty/error 상태를 표현할 오류 코드가 정의됨
